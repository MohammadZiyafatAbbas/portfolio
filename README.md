## ⚡ Deployment Guide (Vercel)

This website is static-ready and can be deployed to Vercel in seconds using either method below:

### Option A: Via Vercel Dashboard (Recommended)

1. Push this repository to your GitHub account (`MohammadZiyafatAbbas/portfolio`).
2. Log in to [Vercel](https://vercel.com/).
3. Click **"Add New..."** → **"Project"**.
4. Import your `portfolio` repository from GitHub.
5. Keep default settings (Framework Preset: **Other** / **Plain HTML**).
6. Click **Deploy**. Vercel will automatically host your portfolio and generate an SSL-secured custom URL.

### Option B: Via Vercel CLI

```bash
# 1. Install Vercel CLI globally
npm i -g vercel

# 2. Login to Vercel
vercel login

# 3. Deploy project (from repository root)
vercel --prod
```

## 💻 Local Development

No build servers or node packages required. Simply open `index.html` in any web browser, or use VS Code's Live Server:

```bash
# Using Python builtin HTTP server
python -m http.server 8000
```
Then visit `http://localhost:8000` in your browser.
